# Créditos

Todo el contenido visual de este proyecto es original y fue creado
específicamente para esta demo:

- `public/images/retrato.svg`: retrato ilustrado de la profesional, dibujado
  a mano en SVG para este proyecto.
- `public/images/blog-*.svg`, `public/images/art-*.svg`, `public/images/hero.svg`:
  ilustraciones abstractas generadas por código
  (`scripts/generar-ilustraciones.php`) a partir de formas geométricas simples.
- `public/images/favicon.svg`: icono original del proyecto.

No se usa ningún recurso de terceros (imágenes, fuentes, iconos ni scripts):
la aplicación no carga nada desde dominios externos en tiempo de ejecución.
